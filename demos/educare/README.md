# EduCare Demo — Role-Based Interactive Experience

**EduCare by TB-Solution · ดูแลทุกการเรียนรู้ เติบโตทุกช่วงวัย**

EduCare Demo เป็นแพลตฟอร์มสาธิตที่เชื่อมโรงเรียน ครู และผู้ปกครองไว้ในระบบเดียว
ผู้เข้าชมเลือกบทบาท **ครู · ผู้ปกครอง · ผู้บริหาร** แล้วทดลองใช้งานได้ทันที
- ไม่มี Login, Username, Password หรือการสมัครสมาชิก
- ไม่มี Super Admin ใน Demo นี้
- ไม่มีระบบ Chat และ CCTV
- ใช้ข้อมูลจำลองทั้งหมด ไม่ใช้ฐานข้อมูล

## 1. วิธีเปิดใช้งาน

```bash
cd tb-demo                       # root ของเว็บไซต์ TB-Solution
php -S localhost:8000            # ต้องใช้ PHP 8.1 ขึ้นไป
```

เปิด http://localhost:8000/demos/educare/ หรือกดการ์ด **EduCare** ในส่วน Demo Systems ของหน้าแรก TB-Solution

ถ้าต้องการดู log สำหรับนักพัฒนา (ทั้งฝั่ง PHP และ Console ของ browser): `APP_DEBUG=1 php -S localhost:8000`

### ลองดูข้อมูลเชื่อมโยงกันข้ามบทบาท (แนะนำสำหรับนำเสนอ)

1. เปิด **ครู** → เมนู **การเข้าเรียน** → กด **"ขาดเรียน"** ให้ **น้องภู** (ห้อง K1/1)
2. ระบบแสดง Toast ว่า Notification Engine ส่งแจ้งเตือนผ่าน In-App · Push · LINE และมีรายการปรากฏใน Notification Log
3. กด **เปลี่ยนบทบาท** → เลือก **ผู้ปกครอง** จะเห็นสถานะ "ขาดเรียนวันนี้" กระดิ่งแจ้งเตือนมีตัวเลข และสถานะการส่งแยกแต่ละช่องทาง
4. เปลี่ยนเป็น **ผู้บริหาร** จะเห็นตัวเลข "ขาดเรียนวันนี้" และกราฟเปลี่ยนตามข้อมูลทันที

ถ้าเปิดบทบาทครูและผู้ปกครองไว้คนละแท็บ หน้าผู้ปกครองจะอัปเดตเองและแสดง Toast แจ้งเตือนใหม่ทันทีโดยไม่ต้องรีเฟรช

## 2. ฟีเจอร์ตามบทบาท

| บทบาท | เมนู | สิ่งที่ทดลองได้จริง |
|---|---|---|
| ครู | Dashboard, ห้องเรียนของฉัน, ข้อมูลนักเรียน, บันทึกกิจกรรมประจำวัน, การเข้าเรียน, เมนูอาหาร, Student Portfolio, ระบบสะสมดาว, ประกาศ, ปฏิทินกิจกรรม, รายงาน | ดูรายละเอียดด้านล่างตาราง |
| ผู้ปกครอง | ภาพรวมบุตรหลาน, กิจกรรมประจำวัน, การเข้าเรียน, เมนูอาหาร, Student Portfolio, ดาวสะสม, ประกาศโรงเรียน, ปฏิทินกิจกรรม, รายงานพัฒนาการ, การแจ้งเตือน | ดูรายละเอียดด้านล่างตาราง |
| ผู้บริหาร | Executive Overview, ข้อมูลนักเรียน, สถิติการเข้าเรียน, สถิติกิจกรรม, ผลงานนักเรียน, พัฒนาการนักเรียน, รายงาน, ประกาศและกิจกรรม | ดูรายละเอียดด้านล่างตาราง |

**ครู**
- เลือกห้องเรียน ค้นหานักเรียน และดูข้อมูลนักเรียนรายบุคคล
- เช็คชื่อ มา/สาย/ขาด/ลา และกดเช็คมาเรียนทั้งห้องได้ในครั้งเดียว
- บันทึกกิจกรรมพร้อมรูป Demo หรืออัปโหลดรูปจากเครื่อง (ระบบย่อขนาดให้อัตโนมัติ)
- เพิ่มรายการอาหาร เพิ่มผลงาน มอบดาวและดูประวัติดาว
- เพิ่มประกาศและเพิ่มกิจกรรมในปฏิทิน
- ดูรายงานประจำวันและสั่งพิมพ์

**ผู้ปกครอง**
- สลับดูบุตรหลานได้ (บัญชีสาธิตมีลูก 2 คน: K1/1 และ K2/1)
- ดูสถานะเข้าเรียนวันนี้และปฏิทินการมาเรียน
- ดูกิจกรรมพร้อมภาพแบบขยายได้
- ดูเมนูอาหาร โดยระบบไฮไลต์เมนูที่ตรงกับอาการแพ้ของบุตรหลาน
- ดูผลงาน ดาวสะสม รายงานพัฒนาการ (สั่งพิมพ์ได้)
- ดูการแจ้งเตือนพร้อมสถานะของแต่ละช่องทาง และกฎการแจ้งเตือนแบบอ่านอย่างเดียว

**ผู้บริหาร**
- กรองตามโรงเรียนและช่วงเวลา (7 วัน / 30 วัน / เดือนนี้)
- ดู KPI และกราฟ Chart.js
- ดูสถิติรายห้องพร้อมรายละเอียด
- ค้นหานักเรียน
- ดูรายงาน 3 แบบ สั่งพิมพ์หรือ Export CSV ได้
- ประกาศถึงผู้ปกครองได้

ทุก Dashboard มีปุ่ม **เปลี่ยนบทบาท** (ข้อมูลไม่หาย) **หน้าแรก** และ **Reset Demo Data** ซึ่งมีหน้าต่างยืนยันก่อนล้างข้อมูล
บนมือถือจะมีเมนูลัดด้านล่าง และเปิด Sidebar ได้เต็มเมนู

## 3. Shared Mock Data & Data Synchronization

- `data/seed.php` สร้างข้อมูลกลาง **ชุดเดียว** ด้วย seed คงที่ โดยกำหนดวันที่อิงจาก "วันนี้" เสมอ ข้อมูลประกอบด้วย
  - 2 โรงเรียน (โรงเรียนอนุบาลโพนสูง, โรงเรียนสายรุ้ง) และ 6 ห้อง (K1/1, K1/2, K2/1, K2/2, P1/1, P2/1)
  - นักเรียน 120 คน ผู้ปกครอง 119 คน และครู 10 คน
  - ประวัติการเข้าเรียน 20 วันเรียน
  - กิจกรรม อาหาร ผลงาน ดาว ประกาศ และปฏิทิน
- ทุกชื่อในระบบเป็นชื่อสมมติ ไม่มีข้อมูลเด็กจริง
- ข้อมูลไหลผ่านระบบดังนี้
  1. ตอนเปิดใช้ครั้งแรก เบราว์เซอร์จะคัดลอก seed ไปเก็บใน **LocalStorage** (`educare.demo.v1`)
  2. ทุกบทบาทอ่านและเขียนข้อมูลผ่าน `assets/js/store.js` ซึ่งเป็น Shared Data Store ตัวเดียว
  3. ข้อมูลยังอยู่หลังรีเฟรชหรือเปลี่ยนบทบาท
  4. แท็บอื่นที่เปิดอยู่รับการเปลี่ยนแปลงผ่าน `storage` event
- PHP Session ใช้จำบทบาทล่าสุดเท่านั้น หน้าแรกจึงมีปุ่ม "กลับไปที่ …"

## 4. Notification Engine

ไฟล์ `assets/js/notify.js` จัดการการแจ้งเตือนตามลำดับนี้
1. เมื่อเกิดเหตุการณ์ ระบบเรียก `emit(event, payload)`
2. ค้นหากฎของเหตุการณ์นั้น
3. หาผู้ปกครองที่เกี่ยวข้อง
4. สร้าง Notification Log พร้อมสถานะแยกตามช่องทาง

| Event | Channels (ค่าเริ่มต้น) |
|---|---|
| `student_absent` | In-App · Push · LINE — Immediate — Enabled |
| `student_late` | In-App · Push |
| `student_present` | In-App |
| `daily_activity`, `portfolio_added`, `star_awarded` | In-App · Push |
| `announcement` | In-App · Push · LINE |
| `school_event` | In-App · LINE |

การส่งเป็นการ**จำลอง** ไม่มีการส่ง Push หรือ LINE จริง
- **In-App:** ส่งถึงทันที
- **Push และ LINE:** เปลี่ยนสถานะจาก "กำลังส่ง" เป็น "ส่งแล้ว" ภายใน 1–2 วินาที
- **ผู้ปกครองที่ยังไม่เชื่อม LINE:** ช่องทาง LINE จะแสดงสถานะ "ข้าม"

กฎตั้งค่าไว้ใน `config/app.php` ผู้ปกครองดูกฎได้แบบอ่านอย่างเดียว ส่วนหน้าจัดการกฎกลางไม่มีใน Demo นี้

## 5. Tech Stack & โครงสร้างไฟล์

PHP 8 (Native), HTML5, CSS3, JavaScript, Bootstrap 5.3.3, Bootstrap Icons 1.11.3, Chart.js 4.4.1, ฟอนต์ Sarabun + Inter ไม่ใช้ Database และไม่ใช้ Framework อื่น

```
demos/educare/
├── index.php              # Demo Landing Page + เลือกบทบาท
├── app.php                # Dashboard ของแต่ละบทบาท (?role=teacher|parent|executive)
├── config/app.php         # แบรนด์, บทบาท, เมนู, กฎการแจ้งเตือน
├── data/seed.php          # Shared Mock Data (ข้อมูลตั้งต้นชุดเดียว)
├── includes/              # bootstrap (helpers + XSS escape), head, sidebar, topbar, bottom-nav, scripts, footer
└── assets/
    ├── css/educare.css    # Design System
    ├── images/            # logo.svg, preview.svg, demo/*.svg (ภาพกิจกรรมตัวอย่าง)
    └── js/
        ├── store.js       # Shared Data Store (LocalStorage + sync ข้ามแท็บ)
        ├── notify.js      # Notification Engine
        ├── ui.js          # Router, วันที่แบบไทย, modal/toast, photo picker, Reset
        ├── parts.js       # ส่วนแสดงผลที่ใช้ร่วมกันทุกบทบาท (กิจกรรม, ปฏิทิน, ประกาศ, ผลงาน)
        ├── teacher.js  parent.js  executive.js
```

ด้านความปลอดภัย:
- ข้อความที่แสดงผลทุกจุด escape ด้วย `htmlspecialchars` (ฝั่ง PHP) และ `esc()` (ฝั่ง JS)
- ค่า `role` ตรวจกับ whitelist ถ้าไม่ถูกต้อง ระบบจะพากลับหน้าเลือกบทบาท
- ข้อมูลจากฟอร์มตรวจช่องที่จำเป็นและจำกัดความยาว
- รูปที่อัปโหลดต้องเป็นไฟล์รูปภาพ ขนาดไม่เกิน 8 MB และระบบย่อเหลือด้านยาว 480px

## 6. ผลการทดสอบ

- PHP ทุกไฟล์ผ่าน `php -l` และ JS ทุกไฟล์ผ่าน `node --check`
- เปิดทุกหน้า (Landing + ครู 11 + ผู้ปกครอง 10 + ผู้บริหาร 8) ใน Chrome แบบ headless แล้วไม่พบ console error
- ทดสอบ End-to-End ผ่าน Chrome DevTools Protocol ผ่านทั้ง 20 ข้อ ได้แก่
  - **หน้าแรกและการเข้าใช้:** มี 3 บทบาท และไม่มีข้อความ Super Admin หรือ Login
  - **ครูบันทึกขาดเรียน:** เกิด Notification ครบ 3 ช่องทาง และ Log แสดงให้ครูเห็น
  - **ข้อมูลไปถึงผู้ปกครอง:** กิจกรรม ดาว และผลงานที่ครูบันทึกไว้ ผู้ปกครองเห็นครบ
  - **ผู้บริหาร:** ตัวเลขขาดเรียนตรงกับข้อมูล และกราฟแสดงครบ
  - **ความต่อเนื่องของข้อมูล:** ข้อมูลไม่หายเมื่อเปลี่ยนบทบาท และ Reset กลับเป็นข้อมูลตั้งต้นได้
- ตรวจหน้าจอที่ 390px (มือถือ) และ 1440px (Desktop) แล้ว ไม่มีการเลื่อนแนวนอนเกินหน้าจอ
